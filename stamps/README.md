# 刻んだ記録

相互レビューの出来事（依頼・引き受け・レビュー・返事）の番号を、毎日まとめてビットコインに刻んでいます（OpenTimestamps）。

- `YYYY-MM-DD.txt`：その日に初めて刻んだ出来事の番号（イベントID）の一覧
- `YYYY-MM-DD.txt.ots`：その一覧がその時点で存在したことの証明書

確かめ方：`ots verify YYYY-MM-DD.txt.ots`（[OpenTimestamps](https://opentimestamps.org/) の道具）。イベントIDは出来事の中身の指紋なので、中身が1文字でも違えば番号が合いません。
刻んですぐの証明書は「手続き中」です。数時間後にビットコインのブロックに入り、翌日の実行で完成した証明書に置き換わります。
